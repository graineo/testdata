## Metadata

The files are unchanged camera files except for two things, both done by overwriting text with text of the same length
(nothing else was touched): the photographer's name in the copyright and owner fields was replaced by "graineo testset",
and camera and lens serial numbers were replaced by zeros. The shooting data (time, exposure, lens) is still in the
files. There are no keywords, descriptions, titles or location data, and no XMP sidecar files are included.

## Integrity

`SHA256SUMS` lists the checksum of every file (`shasum -a 256 -c SHA256SUMS`).
